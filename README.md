## ماذا أقدّم | What I build

<div dir="rtl">

- **مواقع شركات كاملة:** صفحات خدمات، وصفحات مدن وأحياء لا تُنشر إلا بمحتوى مختلف فعلاً، ومشاريع موثّقة، ومدونة، ونماذج طلب عرض سعر وواتساب.
- **لوحات تحكم** يدير منها العميل كل المحتوى دون كتابة كود، مع صلاحيات حسب الدور.
- **سيو تقني ومحلي:** بيانات منظمة (JSON-LD)، وخرائط موقع، وCanonical، وتحويلات، وروابط داخلية، و`llms.txt` لمحركات الذكاء الاصطناعي.
- **أداء واختبارات:** تخزين مؤقت، وصور WebP بأحجام متعددة، واختبارات آلية.

</div>
